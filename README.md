# Bug Report — BudgetModule

Модуль: `budget_module.py` (BudgetModule)
Тестовый драйвер: `test_budget.py`

| ID | Модуль и метод | Входные данные | Ожидаемый результат | Фактический результат | Статус |
|----|----------------|----------------|---------------------|-----------------------|--------|
| BUG-01 | BudgetModule.status / BudgetStatus.usage | Лимит = 0, расход = 50 | Вычисление usage без ошибки (0 или 100%) | `ZeroDivisionError` при делении `spent / limit` | Исправлен |
| BUG-02 | BudgetModule.set_limit / add_expense | Лимит «1000,50», расход «250,25» (запятая) | Принять сумму с запятой как разделителем | `InvalidOperation: Invalid literal for Decimal` | Исправлен |
| BUG-03 | BudgetModule.statuses | Месяц с пробелами: « 2026-10 » | Нормализация пробелов, корректная фильтрация | Лимиты не находятся (несовпадение строк) | Исправлен (в `_key` добавлен `.strip()`) |

## Описание исправлений

### BUG-01
**Причина:** в `BudgetStatus.__init__` вычислялось `spent / limit * 100` без проверки `limit == 0`.
**Исправление:** добавлена проверка `if limit > 0`, иначе usage = 0 (если расход 0) или 100 (если расход > 0).

### BUG-02
**Причина:** `Decimal(str(value))` не принимает запятую как разделитель дробной части.
**Исправление:** в `_to_decimal` добавлено `value.strip().replace(",", ".")` для строк.

### BUG-03
**Причина:** в `statuses()` фильтрация `m == month.strip()`, но хранимый ключ уже нормализован через `_key`. При передаче месяца с пробелами сравнение давало пустой результат.
**Исправление:** месяц нормализуется через `str(month).strip()` перед сравнением.
